# MiniMax H3 Prompt 保姆级指南

H3 是**音画一体**模型：提示词里画面和声音要一起写，声音不是附赠，是加分项。

## 5 步写法

### 1. 定锚（一句话三锚）

"谁（人物锚）+ 在哪（场景锚）+ 干什么（动作锚）"

例：一位 30 岁左右的女侠，深夜站在客栈门口，推门而入。

### 2. 锁脸（防漂移）

传参考图锁定人物。连续多镜共用同一张参考图 + 同一人物描述词。

### 3. 写声音（分层写）

```
对白："店家，打尖。"（低沉，倦意）
环境声：雨声、木门吱呀、烛火噼啪
音乐：低沉古筝，渐入
```

### 4. 控镜头（一次一个）

多镜头用镜头包写法（1a/1b/2a），每个镜头只给一个运镜。

### 5. 防翻车（六个高频翻车点）

| 翻车点 | 解法 |
|---|---|
| 人物漂移 | 参考图 + 人物锚描述词全程一致 |
| 镜头混乱 | 一次一个运镜；乱了就拆镜头包 |
| 声音失控 | 三层分开写，不堆在一起 |
| 口型错位 | 台词加引号 + 语气注；短句比长句稳 |
| 场景跳变 | 常驻场景锁定（机位/色卡/时段） |
| 风格漂移 | 顶部固定风格块，全片复用 |

## 万能模板（填空即用）

```
[景别+角度]，[人物外貌+服装]，[具体动作]，[场景+时间+天气]，
[布光]，[运镜]，[声音：对白"…"+环境声+音乐]，[风格+色彩]，
[技术：时长/比例]
```
