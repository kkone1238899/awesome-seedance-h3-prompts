# 双模型对照速查：同一创意，Seedance vs H3 分别怎么写

## 要素对照表

| 要素 | Seedance 2.5 | MiniMax H3 |
|---|---|---|
| 人物锁定 | `@image1` + 角色表三面板 | 参考图直传 + 人物锚描述 |
| 运镜 | 精确术语，一条一个 | 一条一个，支持首尾帧 |
| 音频 | `@audio1` 绑定；台词加引号注语气 | prompt 内分层（对白/环境/音乐） |
| 否定表达 | 正说（"站稳"不说"不要摔倒"） | 同样正说 |
| 连续性 | 喂上一镜**实际视频** | 喂上一镜**实际视频** |
| 风格统一 | 顶部固定风格块 | 顶部固定风格块 |
| 省钱 | 480p 抽卡 → 高清 | 低分辨率先跑 → 确认再高清 |
| 单条上限 | 2.0：15 秒 / 720p | 看所用渠道配额 |

## 实战案例 1：雨夜客栈女主登场

**Seedance 2.5 版：**
```
@image1=女主角色表（三面板锁定）
深夜雨夜，女主推开客栈木门，右手按剑，左脚先迈过门槛，
停顿半秒抬眼扫堂。
中景微俯15度，烛火大堂，窗外雨幕。
运镜：dolly in，3 秒中景到近景。
风格块：暗调青橙对比，浅景深，胶片颗粒。
对白："店家，打尖。"（低沉倦意）
环境声：雨声+木门吱呀+烛火噼啪
```

**MiniMax H3 版：**
```
中景微俯，一位黑发高髻、深色交领长衫的女侠，
深夜推开客栈木门，右手按住剑柄，左脚先迈过门槛，
停顿半秒，抬眼扫过堂内。烛火摇曳，窗外雨幕。
布光：暖烛光 + 冷雨夜对比。运镜：缓慢前推。
声音：对白"店家，打尖。"（低沉，倦意）；
环境声雨声、木门吱呀；音乐低沉古筝渐入。
风格：电影感暗调，青橙对比色。16:9，15 秒。
```

**差异点**：Seedance 版依赖 `@image1` 做人物锁定，H3 版把人物描述写进正文；音频写法 Seedance 用绑定+H3 用分层，但两边"台词加引号注语气"通用。

## 实战案例 2：街头换装（卡点变装）

- 核心：首尾帧锁定 + 运镜一致，换装点卡音乐重拍
- Seedance：`@image1`=换装前，`@image2`=换装后，运镜 orbit 环绕，约束"人物位置不变"
- H3：首尾帧模式 + 同一人物锚，声音层写"音乐重拍处切换"

## 实战案例 3：第一人称 POV 喜剧

- 核心：POV 视角 + 手持糙感（去 AI 味的关键）
- Seedance：POV + handheld，`@image1` 锁主角手部/服装
- H3：第一人称视角描述 + 环境声写实（脚步声、呼吸声），糙感靠"设备缺陷"描述
