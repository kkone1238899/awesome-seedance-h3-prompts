# Seedance 2.5 Prompt 实战框架

## 七段式写法（按顺序拼）

```

@image1=人物A（正面/背面/表情三面板角色表）
@video1=运镜参考
@audio1=环境声/音乐参考


（具体肌肉动作，不写情绪词）


景别 / 角度 / 场景布局


（一个运镜，精确术语）


（固定风格块，全局复用）


对白："…"（语气注）
环境声：…
音乐：…


（正说：要什么，不要写"不要…"）
```

## 完整示例：雨夜客栈女主登场

```
@image1=女主：黑发高髻、深色交领长衫（角色表三面板已锁定）

深夜，雨打屋檐。女主推开客栈木门，右手按住剑柄，
左脚先迈过门槛，停顿半秒，抬眼扫过堂内。

中景，微俯 15 度。客栈大堂，烛火摇曳，窗外雨幕。

运镜：缓慢前推（dolly in），3 秒从中景到近景。

风格块：电影感，暗调，青橙对比色，浅景深，胶片颗粒。

对白："店家，打尖。"（低沉，带着倦意）
环境声：雨声 + 木门吱呀 + 烛火噼啪
音乐：低沉古筝拨弦，渐入

她站稳，双脚扎地，目光锁定镜头方向。
```

## 10 条铁律（175 节官方课程沉淀）

1. 角色表一次建好反复用：16:9 三面板（无头全身背面/无头全身正面/表情特写），一张表只放一张脸
2. 先低成本抽卡：480p 跑 4 条挑 keeper，再上 1080p/4k（高清费用约翻倍）
3. 正说不说"不要"：写"他站稳"不写"不要摔倒"
4. 风格块置顶复用：全局问题修风格块，单镜头问题改单条
5. 15 秒一个镜头包，镜头按 1a/1b/2a 命名
6. 置换先列保持项：脸部特写单独传图
7. 连续性喂上一镜实际视频，不喂文字梗概
8. 对白戏从全景开场再切入
9. 每轮 4 条：1 条失败重抽，4 条同败重写 prompt；一次只改一个变量
10. 换脸分两遍：第一遍定场景姿态，第二遍换脸；夜景+换脸是高危组合

## 常见翻车与修法

| 翻车 | 先定位 | 修法 |
|---|---|---|
| 脸漂移 | 资产 | 角色表三面板 + 同一 @tag 锁定 |
| 人物瞬移 | 空间 | 俯视布局图 + 常驻场景锁定（机位/色卡/时段） |
| 运镜混乱 | 机位 | 一条只给一个运镜，重写该段 |
| 口型对不上 | 音频 | 台词加引号 + 语气注；1080p 以上更稳 |
| 画面有乱码文字 | 约束 | 清理画面文字杂物（会变异），约束段声明"画面无文字" |
