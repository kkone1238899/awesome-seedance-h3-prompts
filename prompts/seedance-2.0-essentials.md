# Seedance 2.0 Prompt 要点

## 硬约束（先记住这些）

- 单条上限 **15 秒**、720p，长片必须分段
- `@image1` `@video1` `@audio1` 引用，输入文件合计 **≤12 个**
- 素材引用语法：`@image1` 直接写在 prompt 里对应位置

## 时间线写法（2.0 最吃的一套）

```
[0-2s] 钩子镜头：……
[2-6s] 发展：……
[6-10s] 转折：……
[10-15s] 收尾：……
```

每段配：镜头 + 灯光 + 声音（三件套不拆开写）。

## 2 秒钩子

前 2 秒决定 50% 去留。钩子单独写一行，示例：

- 反常识动作开场（倒着走路的人群）
- 强对比（黑白转彩色）
- 悬念提问式画面（门后是什么）

## 运镜术语表（2.0 精确词优先）

推（dolly in）/ 拉（dolly out）/ 摇（pan）/ 移（truck）/ 跟（tracking）/
升（crane up）/ 降（crane down）/ 环绕（orbit）/ 手持（handheld）/ 第一人称 POV

一条 clip 只用一个。"电影感"这类词对 2.0 无效，换成具体机位 + 布光。

## 省钱流程

1. 480p 低清试条（方向验证）
2. 人工检查提示词 → 确认方向
3. 再生成正式版

自动化停在需要人的地方：试条阶段别省人工检查。
